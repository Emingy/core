# Typography

| Prop          | Type                                       | Default                                           | Description                                                                                                                                                         |
| ------------- | ------------------------------------------ | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------- | ------------ |
| `weight`      | "medium" \| "semibold" \| "bold"           | —                                                 | Sets the font weight. e.g. 'medium'                                                                                                                                 | 'semibold'  | 'bold'       |
| `className`   | `string`                                   | —                                                 | Additional CSS class name(s) to apply to the root element.                                                                                                          |
| `elementType` | `ElementType`                              | `(determined by component type, e.g., 'h1', 'p')` | Allows overriding the default HTML tag used for rendering. Useful for rendering text styles with different semantics (e.g., 'span', 'div').                         |
| `isItalic`    | `boolean`                                  | `false`                                           | Determines if the text should be rendered with an italic font style.                                                                                                |
| `align`       | "center" \| "right" \| "justify"           | —                                                 | Sets the horizontal alignment of the text. e.g. 'center'                                                                                                            | 'right'     | 'justify'    |
| `isTruncated` | `boolean`                                  | `false`                                           | Truncates single-line text with an ellipsis (...) if it overflows its container. Requires CSS properties like `overflow: hidden` and `white-space: nowrap`.         |
| `maxLines`    | `number`                                   | —                                                 | Limits the text to a specified number of lines, appending an ellipsis on overflow (multiline truncation). Requires specific CSS support (e.g., -webkit-line-clamp). |
| `textCase`    | "uppercase" \| "lowercase" \| "capitalize" | —                                                 | Applies a text case transformation (e.g., UPPERCASE, lowercase). e.g. 'uppercase'                                                                                   | 'lowercase' | 'capitalize' |
