# Avatar: Image Component with Loading State

The `Avatar` component displays a user image with automatic loading-state management and a
person-icon placeholder for when there's no image (or it fails to load). Depending on the props
passed, it renders as a `<button>`, a router `<NavLink>`, a plain `<a>`, or a plain `<div>`.

---

## I. Component Usage

<Markdown>
{`
\`\`\`tsx
import { Avatar } from '@emingy/core/ui';

// Simple avatar (renders as a div)

<Avatar src="/user-avatar.jpg" alt="User Avatar" />

// Clickable avatar (renders as a button)

<Avatar src="/avatar.jpg" alt="Avatar" onClick={() => console.log('Avatar clicked')} />

// Avatar as an internal route link (renders as a react-router NavLink)

<Avatar src="/avatar.jpg" alt="Avatar" to="/profile" />

// Avatar as a plain link (renders as an anchor)

<Avatar src="/avatar.jpg" alt="Avatar" href="https://example.com/profile" />

// Avatar without an image (shows the person-icon placeholder)

<Avatar alt="No image yet" />

// Avatar with callbacks

<Avatar
  src="/image.jpg"
  alt="Image"
  onLoad={() => console.log('Image loaded successfully')}
  onError={() => console.log('Failed to load image')}
/>
\`\`\`
`}
</Markdown>

---

## II. Component Props

<Markdown>
    {`
| Prop Name | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| **\`src\`** | \`string\` | | The URL of the image to display. When omitted, the person-icon placeholder is shown. |
| **\`alt\`** | \`string\` | | Alternative text for the image (accessibility). |
| **\`className\`** | \`string\` | | Additional CSS classes for custom styling. |
| **\`onClick\`** | \`MouseEventHandler<HTMLButtonElement>\` | | Renders the Avatar as a \`<button>\`. Mutually exclusive with \`to\` and \`href\`. |
| **\`to\`** | \`string\` | | Renders the Avatar as a react-router \`NavLink\`. Mutually exclusive with \`onClick\` and \`href\`. |
| **\`href\`** | \`string\` | | Renders the Avatar as a plain \`<a>\`. Mutually exclusive with \`onClick\` and \`to\`. |
| **\`disabled\`** | \`boolean\` | \`false\` | Disables the button (only meaningful together with \`onClick\`). |
| **\`onLoad\`** | \`() => void\` | | Callback fired when the image loads successfully. |
| **\`onError\`** | \`() => void\` | | Callback fired when the image fails to load. |
`}
</Markdown>

**Note:** All standard HTML image attributes are supported and passed through to the `<img>` element.

---

## III. Root Element

The rendered root element depends on which of `onClick` / `to` / `href` is passed:

<Markdown>
{`
\`\`\`tsx
// onClick → button
<Avatar src="/avatar.jpg" onClick={() => {}} />

// to → react-router NavLink (internal navigation)
<Avatar src="/avatar.jpg" to="/profile" />

// href → plain anchor
<Avatar src="/avatar.jpg" href="https://example.com" />

// none of the above → plain div (non-interactive)
<Avatar src="/avatar.jpg" />
\`\`\`
`}
</Markdown>

`onClick`, `to`, and `href` are mutually exclusive — passing more than one is a type error.

---

## IV. Loading State

The component automatically manages loading state when `src` is provided:

- The spinner is displayed immediately when the component mounts with a `src`
- The image element is hidden (via CSS) while loading
- When the image loads successfully, `onLoad` is called and the spinner is removed
- When the image fails to load, `onError` is called, the spinner is removed, and the person-icon
  placeholder is shown instead
- If the `src` prop changes, the loading state resets and the spinner appears again
- Without a `src`, no loading state is entered — the placeholder is shown immediately

---

## V. Placeholder

When there is no image to show — either because `src` was never passed, or the image failed to
load — the component shows a standard person-icon placeholder instead of a broken `<img>`:

<Markdown>
{`
\`\`\`tsx
// No src → placeholder shown immediately
<Avatar alt="No avatar yet" />

// Broken src → placeholder shown after the error
<Avatar src="/broken.jpg" alt="Broken avatar" />
\`\`\`
`}
</Markdown>

---

## VI. Image Src Changes

When the `src` prop changes, the component automatically resets the loading state via `useEffect`,
causing the spinner to appear again while the new image loads.

## VII. Styling

<Markdown>
{`
\`\`\`tsx
// Loading
<button class="Avatar Avatar__loading">
  <div class="Avatar__loader"><svg><!-- Spinner --></svg></div>
  <img src="..." />
</button>

// Loaded
<button class="Avatar">
  <img src="..." />
</button>

// Placeholder (no src, or load error)
<div class="Avatar Avatar__placeholder">
  <svg><!-- person icon --></svg>
  <img />
</div>
\`\`\`
`}
</Markdown>

**CSS Classes:**

- `Avatar` — base class, always applied to the root element
- `Avatar__loading` — applied to the root while the image is loading
- `Avatar__loader` — container for the spinner
- `Avatar__placeholder` — applied to the root when the person-icon placeholder is shown

---

## VIII. Important Notes

<Markdown>
    {`
- The root element is a \`<button>\`, a \`NavLink\`, an \`<a>\`, or a \`<div>\` depending on which of
  \`onClick\` / \`to\` / \`href\` is passed — these props are mutually exclusive.
- The person-icon placeholder is shown whenever there is no successfully loaded image (no \`src\`,
  or the image failed to load), replacing the \`<img>\`.
- The \`disabled\` prop only has an effect when \`onClick\` is passed (button root).
- The \`onLoad\` and \`onError\` callbacks are optional but recommended for error handling.
- All HTML image attributes (except \`className\`, \`onLoad\`, \`onError\`) are passed to the \`<img>\` element.
- The loading state is managed internally — you don't need to control it manually.
`}
</Markdown>
